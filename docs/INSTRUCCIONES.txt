========================================
    APP-STOCK - SISTEMA DE INVENTARIO
========================================

BIENVENIDO AL SISTEMA DE GESTION DE INVENTARIO Y VENTAS

========================================
    INSTALACION
========================================

1. Ejecute el instalador (App-Stock-Installer-v1.0.exe) como administrador
2. Siga los pasos del asistente
3. ¡Listo! Ya puede usar el sistema

No hace falta instalar ni configurar ninguna base de datos: App-Stock
guarda todo en un archivo local (SQLite) que crea automáticamente la
primera vez que se abre.

========================================
    FUNCIONALIDADES INCLUIDAS
========================================

✅ GESTION DE PRODUCTOS
   - Agregar, editar, eliminar productos
   - Control de stock automatico
   - Busqueda por codigo de barras

✅ SISTEMA DE VENTAS
   - Carrito de compras intuitivo
   - Calculo automatico de totales
   - Tickets de venta en PDF
   - Impresion directa

✅ REPORTES PROFESIONALES
   - Exportacion a PDF y Excel
   - Graficos de productos mas vendidos
   - Historial completo de ventas
   - Anulacion de ventas

✅ ARTICULOS VARIOS
   - Venta de productos no registrados
   - Ideal para servicios o productos especiales

========================================
    REQUISITOS DEL SISTEMA
========================================

- Windows 10 o superior
- 4 GB RAM minimo
- 500 MB espacio en disco
- No requiere conexion a internet para funcionar

========================================
    DONDE QUEDAN LOS DATOS
========================================

La base de datos (productos, ventas) se guarda en:
%LOCALAPPDATA%\App-Stock\app_stock.db

Para hacer un backup, alcanza con copiar ese archivo a otro lugar
(por ejemplo un pendrive) con la app cerrada.

========================================
    SOPORTE TECNICO
========================================

Si tiene problemas, reinicie la aplicación. Si persisten, contacte
a quien le instaló el sistema.
